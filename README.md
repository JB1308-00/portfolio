README: Portfolio & Project Archives

Welcome to my project portfolio. This repository serves as a central hub for navigating my work, structured as a local-first browsing experience. To maintain the intended visual fidelity and interactive flow, please follow the steps below to set up the environment on your machine.

Getting Started

To view the portfolio and its associated projects, follow these steps:

Download the Portfolio: Download this repository as a ZIP file and extract it to your preferred directory.

Launch the Hub: Locate and open the index.html file in your web browser to begin the experience.

Access Project Repositories: As you browse the portfolio, you will encounter various project entries. To view the source or local builds of these specific projects:

Navigate to the corresponding repository on my GitHub profile.

Download the repository as a ZIP file.

Open the local index.html (or the primary entry point) within that specific project folder.

📂 Navigation Structure

This portfolio is designed to be an immersive directory of my technical and creative work. Each entry provides context for the project:

Direct Redirects: Some entries will link you directly to live deployments or external documentation.

Contextual Overviews: Other entries provide high-level technical breakdowns and documentation to explain the architecture and intent behind the work.

🛠️ Tech Stack & Requirements

Environment: A modern web browser (Chrome, Firefox, Safari, or Edge).

Method: No local server or complex dependencies are required for the primary navigation; it is optimized for local file system browsing.

Note: Each repository is a self-contained environment. For the best experience, ensure you have extracted the files fully before opening the entry points.
